# 产品范围

## 产品概述

`okx-bot` 是围绕 OKX 加密货币市场的算法交易工作区，专注于策略研究、因子的回测挖掘、门控后的实盘执行，以及支撑这些工作流可审计的文档体系。

## 用户

- 智能体操作员
- 人工审核员
- 策略负责人（维护具体策略线，如 `fair_value_discount`）

## MVP 范围

- 主流策略线的研究与因子挖掘循环编排
- 具备修复与重启证据的门控实盘执行
- 主流策略与隔离测试面板的结构化运行时报告
- 描述当前受支持行为的稳定归属文档

## 延后范围

- 通用多策略控制平面
- 完整的生产级前端应用
- 由数据库承载的工作流状态

## 成功指标

- 受支持循环可通过仓库内文档与脚本被理解并执行。
- 当前策略线具备清晰的归属文档、运行时证据与命令路径。
- 测试面板能够读取隔离的运行时输出，且不影响实盘策略运行时。

## 约束

- 实盘执行必须保持门控。
- 运行时证据以文件形式承载，除非后续归属文档变更该基线。
- 不要把已废弃策略的结论混入当前受支持的策略线。

## 规则

本文件归属当前里程碑的范围。

不要在此处重复稳定的应用界面与工作流；当前受支持行为请写入 `docs/design/app-overview.md`。

具体实施排序请放入计划文档，而非本文件。
