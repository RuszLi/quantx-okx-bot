## 结论

### 1. Phase 0 报告的 ABORT 是对的，但被否定的层级要厘清

- 被证伪的是「OI 5-min diff 可代理真实清算流」这条数据假设（EV -0.41R vs +0.56R，4-5 σ 偏离，已属结构性否定）。
- 未被证伪的是「清算过冲 → 1-5 min 均值回归」这条策略假设（文献+大所闭源做市数据仍支持）。
- 第 10 章这一分层判断是正确的，继续沿用。

### 2. 你触到的真正天花板不是策略，是预算结构错配

- V2 主策略对真实 liquidation tick 流的依赖是硬需求，不是 nice-to-have。
- 2026 年时点，Binance liquidationSnapshot 下架、Coinbase free tier 限流到 500、Coinglass/Tardis 全部 paywall — 这不是临时问题，是各所统一收口策略。
- $7 本金 × 月度 $30-100 数据费 = 永远 EV 为负，无论策略本身多好。

### 3. V1/V2 都不能复活

- V1：200-400ms 延迟 + 追点火 = 与 HFT 同向竞速，必输。已死，不要回头。
- V2 主策略：数据基建在你的预算下不可达。Phase 1 不应启动。

### 4. 当下只有一条资金/数据/edge 三维同时成立的路径

- 报告里 Option B（OKX 新合约上市波动收割）是唯一 ① 数据 0 成本 ② 散户行为型 edge 短期不会消失 ③ 频次匹配你能盯盘的节奏 的路径。
- 你已经在 V2 §3 里写过雏形，但还没回测验证 — 这是你当前最应该烧的下一颗子弹。

### 5. 目标本身也要重校准（这一点 V2 §9 已经偷偷露出来过）

- $7 → $50（700% / 7 天）隐含 daily edge ≈ 33%，地球上没有任何稳定策略能复利出这个数。
- 这个目标只有在「连胜 + 顶杠杆 + 一次没爆仓」的右尾路径上成立，概率 V2 §9 自己估的就是 15-65%，长期重复采样 EV 必然趋于归零。
- 真正值钱的产出不是 $50，是这一路下来的回测框架 + 数据管道 + 状态机 + Paper→Live 工具链。$50 是娱乐，框架是资产。

在 Option B 跑回测的同时，并行铺 2-3 条 zero-data-cost 策略做横向比较，避免单点失败：

1. **资金费率极值反转**：OKX funding 公开 API，funding > 24h P99 时做对手盘，目标=下一次结算回归
2. **BTC-Altcoin β 失衡**：BTC 1h 振幅 < 0.3% 但 alt 偏离 N σ 时，fade alt 回中位数
3. **周末流动性收割**：UTC Fri 22:00-Sun 22:00 窗口，低流动性下 wick 后 mean reversion
