## Goal

交付一条**可复用、可审计、可自动晋升/淘汰**的 edge discovery pipeline，使其能够：

1. 从免费市场数据（OKX/Binance 公共 API）批量生成候选信号族。
2. 对每个候选信号在受控回测中评估基础指标（WR / EV(R) / PF / max_consec_losses / max_dd）。
3. 通过多路径交叉验证（CPCV / WFA）和多重测试校正（DSR / PBO）过滤过拟合。
4. 对通过全部闸口的策略，自动生成符合 `docs/strategies/00-strategy-template.md` 的策略档案。
5. 将晋升候选自动注册到 `src/backtest/strategies/__init__.py` 与 V3 编排器配置，并触发 exit-klines 对齐回归测试。
6. 为未通过策略生成结构化“死亡记录”（negative evidence），存入 `docs/strategies/` 并将阶段标记为 `rejected`。

本计划的直接结果是**管道框架落地**，并至少用 Alpha/Gamma 两族信号作为第一批种子验证管道能否从 ABORT 中筛选出 REPARAM 或 PASS 配置。

---

## Non-Goals

1. **不承诺找到一定能 live 的 edge。** 本计划交付的是发现方法论，不是某条具体策略。
2. **不修改 V3.1 已 ABORT 策略的原始逻辑。** 它们将通过参数空间搜索或信号族变体形式被重新评估，而不是手工修补。
3. **不接入付费数据源。** 所有信号必须基于 kline、order book、OI、funding、liquidation、公告等免费数据。
4. **不实现全自动 live 交易。** pipeline 的输出是“晋升候选”，进入 paper 阶段仍需独立计划。
5. **不替代现有工程规范。** pipeline 必须复用现有 `Strategy` Protocol、`ExecParams`、exit-klines 对齐检查、OKX SDK 规范。
