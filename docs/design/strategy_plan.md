# 微观结构动量点火与清算猎手 (The Vulture) - 策略方案

## 1. 核心目标与约束
- **初始资金**: $7
- **目标资金**: $50 (700% 收益)
- **时间预期**: 极短期 (期望 1 天内完成)
- **网络延迟**: 200ms ~ 400ms (通过本地代理至 OKX 服务器)
- **核心理念**: 极端投机，放弃传统风控，利用高杠杆捕捉市场微观结构失衡瞬间的单边动量。

## 2. 核心哲学 (The Edge)
在 200-400ms 的延迟下，无法进行高频做市 (HFT)。本策略的 Alpha 来源于**高杠杆散户的强制平仓（爆仓）**。
当价格突破关键点触发大量止损和爆仓单时，这些市价单会无视价格消耗订单簿流动性，导致价格在短时间内（30秒 - 2分钟）出现极端单边移动。
策略目标是在**火势蔓延的初期**（清算级联发生时）入场，并在动量耗尽前逃顶。

## 3. 交易品种选择 (The Fuel)
- **目标**: OKX 上的 **高波动、低市值、近期热门的 Altcoin 永续合约（Perpetual Swaps）**。
- **特征**: 订单簿较薄（Thin Order Book），散户参与度高，极易发生连环爆仓。
- **排除**: 绝对不碰 BTC、ETH（流动性过好，做市商主导，延迟劣势会被放大）。

## 4. 核心信号逻辑 (The Trigger)
完全基于 WebSocket 实时数据流（`Trades` 成交频道, `BBO` 最优买卖价, `Open Interest` 未平仓合约），在 **10秒到30秒** 的微观时间窗口内计算以下指标：

1. **信号 A：订单流失衡 (Order Flow Imbalance, OFI)**
   - 监控 BBO 变化。买盘挂单急剧增加且卖盘被迅速消耗，预示上行动量；反之亦然。
2. **信号 B：成交量差 (Volume Delta, VD)**
   - `VD = 主动买入市价单成交量 - 主动卖出市价单成交量`
   - 寻找过去 10 秒内 VD 出现 > 3 个标准差的极端尖峰。
3. **信号 C：未平仓量骤降 (OI Drop) —— 核心确认信号**
   - VD 出现尖峰的**同时**，Open Interest 瞬间下降。这表明巨大成交量源于**爆仓/止损 (Forced Liquidation)**，而非主动建仓。

**开仓条件（满足其一即可）**：
- **多头点火**: VD 极度为正 + OI 骤降 + 价格在 10 秒内上涨 > 0.5%。市价做多。
- **空头踩踏**: VD 极度为负 + OI 骤降 + 价格在 10 秒内下跌 > 0.5%。市价做空。

## 5. 资金管理与执行 (The Flip)
- **杠杆率**: 20x - 30x (根据 OKX 币种限制，尽可能拉满)。
- **仓位**: 每次满仓 (All-in 当前可用资金)。
- **入场**: **必须是市价单 (Market Order)**。
- **出场 (逃顶)**:
  - **不设固定止盈**。实时监控 VD，一旦 VD 方向反转或动量停滞超过 15 秒，**立刻市价平仓**。
- **止损**: 
  - 极窄的微观结构止损：入场后 5 秒内价格未顺势移动，立刻平仓（仅亏损手续费和滑点）。
  - 极端模式下可不设硬止损，接受单次爆仓风险（7刀当作期权权利金）。

## 6. 架构与技术实现
1. **语言/框架**: Python (`asyncio` + `websockets`) 或 Node.js。全异步架构。
2. **网络连接**: 保持与 OKX 的 WebSocket 交易 API 连接，以最小化下单延迟。
3. **数据处理**: 放弃数据库，所有 OFI 和 VD 计算在内存中通过环形缓冲区 (Ring Buffer) 实时完成，保持 O(1) 复杂度。
