## 0. 核心范式转换

- **旧方案错在**：追清算（你和清算一起冲，最后接最后一棒）
- **新方案对在**：Fade 清算（让清算冲完，做对手盘吃均值回归）

清算是 price-insensitive 的强制单流，短时把价格推离 fair value，1-5 分钟内回归 30-70%。
你 200-400ms 延迟无法和 HFT 抢点火点，但清算尘埃落定后的均值回归窗口给你足够时间——这条转换让"延迟劣势"瞬间变成"延迟无关"。

## 2. 主策略：Liquidation Cascade Fade（清算反弹做空/做多）

### 2.1 Alpha 来源
- 强制平仓单 = 不计价的市价流
- 价格短时偏离 fair value，1-5 分钟内回归 30-70%
- Coinglass / Hyblock 数据已证实存在
- 散户无脚本化执行能力 → edge 存活

### 2.2 数据订阅（直接拿清算流，丢掉 OI 代理）
- **OKX**: `liquidation-orders`（强平张数+方向+价格）
- **Binance**: `!forceOrder@arr`（全市场领先指标）
- **Bybit**: `liquidation.{symbol}`（交叉确认）
- **OKX**: `books5` + `trades` + `mark-price`（执行用）

### 2.3 入场触发（5 个 AND 条件）

| 条件 | 阈值 | 含义 |
|---|---|---|
| 60 秒滚动清算 USD 量 | > 24h 滚动 P95 | 异常清算，非日常 |
| 单方向清算占比 | > 80% | 单边踩踏，非洗盘 |
| 价格偏离 VWAP(15m) | > 1.5 × ATR(15m) | 已过度偏离 |
| 清算速率二阶导 | 转负（减速） | 级联接近尾声 |
| 资金费率 | 仍未中性化 | 过度杠杆仓位还在 |

- **入场方向**：清算多头堆 → 做多反弹；清算空头堆 → 做空反弹
- **入场方式**：post-only limit at mid ± 1 tick；未成交则放弃此次机会

### 2.4 出场（双轨）
- **目标 1**：回归至偏离 fair value 的 50%（动态止盈，平均 +2-3%）
- **目标 2**：硬时间出场，90 秒未达目标 1 则平仓
- **硬止损**：入场价反向 1.2%（按权益约 -15% ~ -20%）

### 2.5 仓位与杠杆
- **杠杆**：10-15x（**不是 30x**——30x 在 1.2% 止损前就被滑点+维持保证金吃掉）
- **单笔权益风险**：固定 **20%**（不是满仓）
- **预期 R:R**：1 : 1.6

### 2.6 数学期望
- 经验胜率：**58-62%**（来自 Coinglass 清算数据回测，需自行验证）
- 单笔 EV = 0.60 × 1.6R − 0.40 × 1.0R = **+0.56R ≈ +11.2% 权益**
- $7 → $50 ≈ **18-20 笔净胜利**
- 8 笔/天合理频率下，3-7 天达成 $50 概率 ~40-65%

## 3. 辅助策略：OKX 新合约上市波动收割

### 3.1 Edge 来源
- OKX 新永续上市前后 30 分钟内 IV 远高于稳态
- 上市时间公告确定 → 零延迟竞赛
- 散户 FOMO / 砸盘模式高度可重复

### 3.2 玩法
**A. Pump-then-Fade（推荐）**
- 上市后前 5 分钟观察 high
- 价格回踩至 high × 0.85 时做空
- 目标：回到上市开盘价附近，止损过前高

**B. Pre-list straddle on correlate**
- 若该币种在 Gate / MEXC 已有现货，公告后做多现货 + 上市后 fade

### 3.3 频率
- OKX 每周 2-4 个新永续，作为主策略补充

## 4. 资金管理状态机

> Kelly criterion 与路径连续性是数学约束，违反它 EV 即为负，与"风控泛谈"无关。

| 规则 | 触发 | 行为 |
|---|---|---|
| 单笔风险上限 | 永远 ≤ 20% 权益 | 不可超 |
| 连续 2 笔亏损 | — | 冷却 30 分钟 |
| 权益 > $14（翻倍） | — | 单笔风险降至 15% |
| 权益 > $25 | — | 单笔风险降至 10% |
| 权益 ≥ $50 | — | 提现 $40，剩下继续打 |

## 7. 技术架构

```
┌─ Binance liquidations WS ──┐
├─ Bybit liquidations WS  ──┤→ Aggregator → Signal Engine → Order Manager → OKX REST/WS
└─ OKX liq + book + trade ──┘                ↑                   ↓
                                       Symbol Universe       Position State Machine
                                       (excl BTC/ETH,
                                        top 5-50 by vol)
```

- **语言**：Python `asyncio` + `websockets` + `uvloop`
- **数据**：所有清算源必须多所聚合，仅订阅 OKX = 漏报 + 滞后
- **回测先行**：用 Tardis.dev / Coinglass 历史数据离线跑 30 天，验证胜率假设
- **Paper 24h**：实盘前 dry-run 一天，确认信号触发频率符合预期
- **内存计算**：环形缓冲区做 1/15/60 秒滚动窗口，O(1) 复杂度
- **断线重连**：WS 心跳 + 自动重连 + 重连后强制 reconcile 仓位
