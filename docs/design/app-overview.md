# 应用概述

## 用途

说明当前支持的应用层基线。

## 当前应用界面

- 主要界面或页面：脚本驱动的研究循环、实时/研究报告运行时面板、隔离的测试可视化面板运行时。
- 主要导航模式：命令行与基于文件的面向，而非面向用户的导航外壳。
- 主要用户角色：智能体操作员、人工审核员、以及策略专属的实时/研究监督者。
- 核心工作流：采样、选区、门控、实时尝试、对账、审计、诊断、修复、重启、面板预览。
- 关键领域对象：策略 ID、目标 ID、阶段策略、门控报告、实时尝试、对账报告、测试面板运行时文件。
- 集成点：Polymarket BTC 5m 市场数据、本地运行时 JSON / JSONL 证据、PowerShell 控制脚本、Python 报告脚本。
